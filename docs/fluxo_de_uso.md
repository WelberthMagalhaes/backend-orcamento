# Fluxo de Uso do Sistema de Orçamento

## 1. Cadastro de Clientes
- Usuário acessa a tela de **clientes**.
- Pode criar, editar ou listar clientes.
- Cada cliente possui informações básicas de contato.

## 2. Criação de Orçamentos
- Usuário acessa a tela de **orçamentos**.
- Seleciona o cliente ao qual o orçamento pertence.
- Adiciona itens e serviços ao orçamento.
- Define valores, prazos e condições.

## 3. Envio de Orçamentos
- Após finalizar, o usuário pode **enviar o orçamento** para o cliente.
- O envio gera uma **versão congelada** do orçamento.
- Caso o cliente solicite alterações, é criada uma **nova versão do orçamento**.

## 4. Gestão de Versões de Orçamentos
- Cada orçamento pode possuir múltiplas versões.
- O histórico é preservado para referência futura.
- O usuário entende que, após o envio, alterações só são feitas criando uma nova versão.

## 5. Status e Acompanhamento
- O orçamento pode ter status como: **Rascunho**, **Enviado**, **Aprovado**, **Rejeitado**.
- Usuário pode acompanhar o andamento e interações do cliente.

---

📌 Este fluxo descreve o **caminho típico do usuário** dentro do sistema.
